# Brand files

The mark is a gate on a ground line, with one fact inside it. The yellow square is the
`evidence` color (`#ffe066`), the same color that marks a cited value in `groundgate review`.

| File | Use |
|---|---|
| `groundgate-mark-light.svg`, `groundgate-mark-dark.svg` | The mark alone, on a light or a dark page |
| `groundgate-lockup-light.svg`, `groundgate-lockup-dark.svg` | The mark and the name. The name is outlined, so no font is needed |
| `groundgate-lockup-light.png`, `groundgate-lockup-dark.png` | The same, 2x PNG on a clear ground, for tools that do not show SVG |
| `groundgate-icon.svg` | The mark in white on a square ink tile |
| `groundgate-icon-512.png` | An avatar or a package page |
| `groundgate-icon-180.png` | A touch icon |
| `groundgate-icon-32.png`, `favicon.ico` | A favicon. The ICO holds 16, 32 and 48 px |
| `groundgate-social.png` | The 1280 x 640 link preview, for the repository settings and link cards |

Rules:

- Write the name in lowercase, also at the start of a sentence.
- Do not recolor the yellow square. Do not add shadows, gradients or round corners.
- Keep clear space of one post width (6/64 of the mark) on each side of the mark.
- The type is IBM Plex Sans SemiBold for the name and IBM Plex Mono for values and codes.
